Option C · A separate lobby screen

The duel gets its own screen, so the game page is never cluttered with settings. Start it from the drawer. One phone makes a room and shows a 4-letter code as tiles in the logo's colours. The other phone types it in, the way you'd type a guess, or opens the shared link. In the game a single slim bar holds both clocks.

Trade-offs

  • + The cleanest split. Duel settings live on their own screen, the game page gets one slim bar, and the drawer gets one button.
  • + A 4-letter room code fits the game. It's easy to say across a table, and the join screen is "type a word", like a guess.
  • + Making and joining are separate, so the joining phone has nothing to choose. No more "both of you type the same room name".
  • − The most new UI to build: a second screen, and making vs joining. The room code needs a hidden suffix (or a second word) so two tables never collide.
  • − A screen change feels heavier than a dropdown for something you set once per game.
